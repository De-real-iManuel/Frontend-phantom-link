# 3D model attribution

No third-party or manufacturer GLB assets are shipped. All models on the Devices page are procedural boxes
generated in code (`src/components/three/`) and are labelled "Illustrative model, not manufacturer CAD".

Manufacturer CAD for the catalogued devices was not obtainable in the build environment (manufacturer sites
returned 403). Sketchfab models with CC Attribution licences exist (for example a Siemens S7-1200 CPU) but
Sketchfab requires an authenticated account to download them, so none were added. See `docs/device-research.md`.

If a GLB is added later, record here: asset name, author, source URL, licence, modifications, and polygon count.
